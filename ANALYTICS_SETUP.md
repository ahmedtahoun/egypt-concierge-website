# Google Analytics 4 Configuration

### Overview
This document outlines the setup for Google Analytics 4 (GA4) including configuration, conversion goals, event tracking, and the reporting dashboard.

### GA4 Configuration
1. **Create a GA4 Property**: Go to the Google Analytics dashboard and create a new GA4 property.
2. **Data Streams**: Set up data streams for the web and/or apps that you wish to track.
3. **Measurement ID**: Obtain the Measurement ID from the GA4 property settings.
4. **Install GA4 Tag**: Use Google Tag Manager or add the GA4 tag directly to the website's code.

### Conversion Goals
1. **Define Goals**: Identify the key actions you want to track as conversions (e.g., form submissions, purchases).
2. **Set Up Goals in GA4**: In your GA4 property, navigate to "Goals" and set up new goals based on the defined actions.
3. **Track Conversions**: Ensure that conversions are being tracked correctly through the real-time view in GA4.

### Event Tracking
1. **Standard Events**: Utilize Google Analytics’ recommended events for common interactions (e.g., page views, clicks).
2. **Custom Events**: Implement custom event tracking for specific actions unique to your website.
3. **Debugging**: Use the GA4 Debug View to ensure that events are firing as expected.

### Reporting Dashboard Setup
1. **Explore Reports**: Familiarize yourself with the Analysis Hub in GA4 to create custom reports.
2. **Create Dashboards**: Use the exploration tools to build dashboards that visualize your key metrics and KPIs.
3. **Share Reports**: Utilize the sharing options in GA4 to distribute your reports to stakeholders.

### Conclusion
Ensure regular monitoring of analytics to optimize performance and achieve desired outcomes.
